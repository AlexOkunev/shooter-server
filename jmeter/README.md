# Нагрузочное тестирование

Для создания начальных данных, требуемых для начала тестирования, в БД необходимо выполнить скрипты из папки init 
Также необходимо выполнить все, что касается разворачивания через helm, в том числе прописывания ingress в /etc/hosts

Если справочники оружия и валюты еще не заполнены, то нужно сначала выполнить нагрузочные тесты по equipment в admin gateway

Во всех тестах нужно обязательно получить токен через keycloak и прописать его в header Autorization
